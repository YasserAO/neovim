# Neovim Configuration

Modular Neovim setup powered by [lazy.nvim](https://github.com/folke/lazy.nvim).

## Features & Plugins
- **Package Manager:** `lazy.nvim`
- **Colorscheme:** `tokyonight.nvim` (transparent background enabled)
- **Statusline:** `lualine.nvim`
- **Navigation / Files:** `telescope.nvim` + `telescope-fzf-native`
- **Harpoon:** `harpoon2` by ThePrimeagen (`<leader>a`, `<C-e>`, `<leader>1..4`)
- **Syntax / Highlighting:** `nvim-treesitter` (master branch) with parsers for DevOps, Web Dev, and core languages
- **Web Development:** `nvim-colorizer.lua` (TailwindCSS & CSS coloring), `nvim-ts-autotag`
- **Git Integration:** `gitsigns.nvim`, `vim-fugitive`
- **Remote / SSH Clipboard:** `nvim-osc52` (seamless copy/paste over SSH)
- **QoL:** `nvim-autopairs`, `which-key.nvim`
